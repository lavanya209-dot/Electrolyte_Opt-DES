# DES Electrolyte Discovery — Reproducible Analysis

Physics-guided machine learning for predicting electrical conductivity, viscosity, and density of Deep Eutectic Solvents (DES), with XGBoost surrogate models and NSGA-II multi-objective optimisation for electrolyte discovery.

This repository accompanies the manuscript *"Physics-Guided Machine Learning for Predicting Electrical Conductivity of Deep Eutectic Solvents: XGBoost Surrogates and Multi-Objective Electrolyte Discovery."*

## How to run

1. Place `DES_ML_Merged_Dataset.xlsx` in the same directory as the notebook (or upload it when Section 2 prompts, if running in Google Colab).
2. Run all cells **in order, top to bottom**. Later sections depend on files written by earlier sections (e.g., Section 5 requires `DES_ML_Ready_Dataset.xlsx` from Section 2).
3. Expect a full run to take several minutes, dominated by Section 5 (15 fold-runs × 3 properties) and Section 8 (4 algorithms × 15 fold-runs × 3 properties).

## Reproducibility notes

- Random seeds are fixed throughout (`42`, `123`, `456` for the repeated-CV runs; `random_state=42` elsewhere), so results should match closely on re-run.
- Minor numerical differences (typically <0.01 in R²) can still occur across different `xgboost`, `scikit-learn`, or `pymoo` versions, or due to `n_jobs=-1` multi-threaded training. If exact reproduction matters, pin package versions (see `requirements.txt` if provided separately, or freeze your environment with `pip freeze`).
- `MLPRegressor` (used only in Section 8 / Table S4) is the least reproducible component, as neural-network initialization can vary slightly across scikit-learn versions and BLAS backends even with a fixed seed.

## Known open issues (not yet resolved)

These are flagged directly in the notebook and should be addressed before the results are treated as submission-final:

1. **Section 10 (Table 4) is inconsistent with Sections 4–9.** It currently trains on `DES_Complete_Properties.xlsx` (the older, 1,024-record, all-3-properties-required subset) and still includes a `log_Viscosity` feature in the density model. Every other section uses the corrected, leakage-free `DES_ML_Ready_Dataset.xlsx` (1,598 records) with an identical 6-feature set across all three properties. **Table 4 needs to be re-run against the corrected dataset/features before it is reported as final.**
2. **Table 1** (manuscript) per-source record counts still need to be updated to sum to 1,598, not the older 1,024.
3. **Table 4b** HBA/HBD abbreviation codes (e.g., `Ca`, `C:OA`, `C:DA`, `C:DOA`) have not been traced back to full chemical names — see the raw `HDB_Database_File5` source or its published data dictionary.
4. **Figure S1** (SHAP summary plot) is referenced in the manuscript text; confirm it is generated and inserted before submission.
5. **Prediction interval calibration is poor.** The corrected bootstrap intervals show only 13.6–24.6% empirical coverage against a nominal 80% (Section 6) — this is reported honestly in the manuscript, but means per-candidate intervals should not be over-interpreted.
