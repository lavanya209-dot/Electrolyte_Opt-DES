This work tackles those gaps through four linked pieces, all built around electrical conductivity. First, we curate and harmonise a multi-source experimental dataset of 1,024 fully characterised DES systems, with conductivity as the primary response variable. The next step involves constructing physics-informed XGBoost surrogate models of electrical conductivity, viscosity and density, through the selection of features that encapsulate the known physics of dispersion transport in DES. Then, we rigorously validate the surrogate models using both random and system-grouped splits to reduce the risk of data leakage. Finally, we perform a multi-objective optimization using NSGA-II where the electrical conductivity surrogate is treated as the primary objective and both viscosity and density are treated as co-objectives, in order to generate Pareto optimal electrolyte formulations for DES. Together, these steps yield a repeatable and physics-consistent approach for conducting an electrical conductivity-based screen of a given set of DES electrolytes.
